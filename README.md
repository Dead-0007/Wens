# وِنس (`Wens PC v1.0.0`) — Local-First Windows Desktop Companion

**وِنس** رفيق سطح مكتب محلي لنظام Windows يجمع بين متابعة الصلاة والعبادة والصيام وبين إدارة المشاريع والأفكار وجلسات التركيز والعمل الإبداعي — مبني بمعمارية **React 19 / TypeScript + Rust / Tauri v2 + SQLite v3 + Win32 Native**.

---

## ما يتضمنه الإصدار `v1.0.0`

### 1. الواجهة الرئيسية (`apps/app-ui` → `dist-vnext/`)
- **واجهة RTL حديثة ومتجاوبة:** تدعم المقاسات حتى `760×600` وتكبير `200%`، مع سمات داكنة وفاتحة (بما فيها سمة `dawn-sand` الفاتحة المتوافقة مع تباين WCAG AA)، وحماية `AppErrorBoundary` للتعافي الآمن.
- **معالج الإعداد الأولي (90 ثانية):** اختيار المدينة من قاعدة مدن عربية وعالمية أوفلاين، أو إدخال الإحداثيات يدويًا مع التعيين التلقائي لطريقة الحساب والمنطقة الزمنية.
- **صفحة «اليوم» (`Today`) ومركز العبادة (`Worship`):**
  - حساب شمسي محلي لـ 18 طريقة حساب معتمدة (المصرية، أم القرى، رابطة العالم الإسلامي، ISNA وغيرها)، مذهب العصر (الجمهور / الحنفي)، تحويل IANA الزمني الديناميكي للتوقيت الصيفي والشتوي، وبدائل خطوط العرض القطبية والعالية.
  - بوصلة القبلة، سجل الصلوات المحتاجة مراجعة والقضاء، سجل الصيام (رمضان، القضاء، النذر، الاثنين والخميس، الأيام البيض) مع التقويم الهجري وتصحيح التاريخ الهجري، متابعة الختمة وورد القرآن، والأذكار اليومية.
- **المشاريع والأفكار والتركيز والاستوديو والسجل:**
  - إدارة المشاريع والأفكار (CRUD كامل على `SQLite v3` مع نافذة تأكيد قبل الحذف `ConfirmModal`، والتقاط فكرة سريع بـ `Ctrl+I`).
  - مؤقت تركيز (`15/25/45` دقيقة) مع إيقاف تلقائي اختياري عند دخول وقت الصلاة، وتسجيل جلسات العمل.
  - شاشة السجل التاريخي (`السجل`) متعددة الأيام، ومعمل الإبداع (Campaign Brief، Creative Matrix، Storyboard، حاسبة CTR/CPC/CPA/ROAS).
  - مركز التنبيهات المحلي.

### 2. الكبسولة الذكية (`Dynamic Island` — `overlay.*`)
- نافذة شفافة عائمة قابلة للطي والتوسيع (اختصار عام `Ctrl+Alt+I`) مع مزامنة دقيقة للـ Click-through ووضع أعلى أو أسفل الشاشة.
- **الوحدات الاختيارية (كل وحدة مستقلة في الإعدادات):**
  - تنبيهات الصلاة وبطاقات الأذكار الدورية.
  - **إذاعة القرآن الكريم (Opt-in):** 33 محطة عبر `HTTPS` فقط مع انتقال تلقائي للرابط البديل، مهلة استعادة عند التوقف، وإيقاف فوري في الوضع الصارم بدون شبكة.
  - **التحكم بالميديا (`Windows SMTC`):** عرض المسار الحالي والتحكم بالتشغيل مع إيقاف تلقائي اختياري وقت الأذان.
  - **الحافظة الذكية (`Smart Clipboard`):** حاسبة ومعاينة ألوان في الذاكرة المؤقتة (RAM) فقط، مع احترام علامات استثناء مديري كلمات المرور في Windows (`CanIncludeInClipboardHistory = 0` و`ExcludeClipboardContentFromMonitorProcessing`).
  - **رف التنزيلات (`File Shelf`):** متابعة التنزيلات داخل مجلد `Downloads` فقط مع تقييد صارم للمسارات القانونية.
  - **مؤشرات خصوصية الكاميرا والميكروفون (`Privacy Dots`):** قراءة حالة `CapabilityAccessManager` من سجل Windows فقط (لا يفتح وِنس الكاميرا أو الميكروفون مطلقًا).
  - **العافية (`Wellbeing`):** متتبع شرب الماء، تذكير قاعدة `20-20-20` للعين، وترحيب العودة بعد الخمول (`GetLastInputInfo`).
  - **تقويم الاجتماعات (`iCal / .ics` — Opt-in):** محلل RFC 5545 محمي ضد SSRF يقبل روابط `https://` فقط عند إدخالها صراحةً من المستخدم.

### 3. شريط مهام Windows الأصلي والنافذة المنبثقة (`Native Win32 Taskbar Strip & Flyout`)
- ويدجت `Win32 GDI` أصلية خفيفة مدمجة داخل شريط مهام Windows (`Shell_TrayWnd`) تعرض الصلاة القادمة والعد التنازلي.
- تتعافى تلقائيًا عند إعادة تشغيل `explorer.exe` (`TaskbarCreated`)، وتدعم تغير الـ DPI والوضع الداكن/الفاتح لنظام Windows، وتفتح نافذة منبثقة تفاعلية (Flyout) بالضغط اليسار لاستعراض الصلوات الخمس أو فتح وِنس أو إيقاف الصوت.

### 4. الرفيق العائم (`Companion Pet` — `pet.*`)
- نافذة شفافة دائمة فوق النوافذ تدعم السحب عبر الشاشات المتعددة بمختلف مقاسات الـ DPI، تتبع حركة المؤشر بالعينين، تنبيهات الصلاة ومؤقت العمل، قائمة سياقية مدمجة، ومؤثرات صوتية إجرائية محلية.

### 5. المحرك الأصلي (`Rust` + `SQLite v3`)
- قاعدة بيانات `SQLite v3` محلية (`WAL` + `busy_timeout` + معاملات `BEGIN IMMEDIATE` + ترحيل تلقائي من `v1/v2` + عزل وإعادة بناء تلقائية عند تلف القاعدة).
- مُجدول تنبيهات Rust مستقل عن النافذة مع إشعارات Windows Toast الأصلية، احترام ساعات الهدوء، وإعدادات افتراضية آمنة للتثبيت الجديد (منبه السحور ومنع السكون مُعطّلان افتراضيًا ولا يعملان إلا بتفعيل صريح من المستخدم).
- تشغيل صوتي محلي عبر `rodio` (أذان، نغمة هادئة، نغمة تركيز، منبه استيقاظ اختياري)، نسخة واحدة فقط (`Single Instance`)، أيقونة System Tray، تشغيل تلقائي مصغّر مع Windows (`--minimized`)، نسخ احتياطي واستعادة عبر مربع حوار Windows الأصلي، إعادة ضبط المصنع مع خيار تصدير نسخة يدويًا قبل المسح، وسجلات دوّارة محلية (`wens.log`) وتقرير تشخيص معقّم.

## الخصوصية والشفافية الشبكية

وِنس مصمم وفق مبدأ **المحلي أولًا (`Local-First`)**:
- **لا توجد حسابات، ولا خوادم سحابية، ولا تتبّع (`Telemetry`)، ولا تقارير أعطال تلقائية.**
- بياناتك الشخصية محفوظة محليًا. قاعدة البيانات في `%APPDATA%\com.wens.offline\wens.sqlite3`، وبعض الإعدادات وبيانات العرض موجودة في التخزين المحلي لنافذة التطبيق.
- **جميع الوظائف الأساسية تعمل أوفلاين بنسبة 100%** (مواقيت الصلاة، القبلة، الهجري، الإشعارات، الأذان، شريط المهام، الرفيق، الكبسولة المحلية، المشاريع، التركيز، والنسخ الاحتياطي).
- **الميزتان الشبكيّتان الوحيدتان (اختياريّتان بالكامل — Opt-in):**
  1. **إذاعة القرآن الكريم:** تتصل ببثوث `HTTPS` عامة (`*.qurango.net`، `*.radiojar.com`، `*.mp3quran.net`) فقط عند ضغط زر التشغيل.
  2. **تقويم الاجتماعات `.ics`:** يجلب رابط `https://` فقط إذا قام المستخدم بلصقه بنفسه في الإعدادات (مع حظر عناوين الشبكة الداخلية والملفات المحلية منعًا لـ SSRF).
- عند تفعيل **الوضع الصارم بدون شبكة (`Strict Offline Mode`)**، يوقف وِنس الإذاعة ويلغي طلبات التقويم الجارية ويحظر طلبات التقويم والبث الجديدة. يتحكم Windows وWebView2 والتطبيقات الخارجية في اتصالاتها بنفسها.

للتفاصيل الكاملة راجع: [`PRIVACY.md`](PRIVACY.md) و[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).

## التشغيل والتطوير والبناء

### المتطلبات
- Node.js 20+ وnpm
- Rust toolchain (`rustup`, `cargo`) + Tauri CLI v2 (`cargo install tauri-cli --version "^2.0.0" --locked`)
- Windows 10/11 (x64) مع WebView2 Runtime (مُضمّن كـ Bootstrapper في المثبّت)

### الأوامر الأساسية

```powershell
# تشغيل واجهة React/TypeScript (vNext) في وضع التطوير
npm run dev:vnext

# بناء واجهة الإنتاج إلى dist-vnext/
npm run build:vnext

# مزامنة أصول سطح المكتب (واجهة vNext + الرفيق + الكبسولة + الأصوات + الخطوط)
npm run desktop:sync

# تشغيل تطبيق Windows Desktop (Tauri) في وضع التطوير
npm run desktop:dev

# بناء نسخة Release + مثبّت Windows (NSIS)
npm run desktop:build
```

> **بناء محمول عبر الأجهزة وCI:** لا يفرض `.cargo/config.toml` أي مسار قرص صلب ثابت؛ يُبنى المشروع افتراضيًا داخل `target/`. يمكنك توجيه مخرجات Cargo إلى قرص أو كاش مخصص بمتغير البيئة القياسي `$env:CARGO_TARGET_DIR` (ويقترح `run-tauri.mjs` تلقائيًا `D:/cargo-target-wens` فقط إذا كان ذلك المجلد موجودًا بالفعل ولم تُحدِّد `CARGO_TARGET_DIR`).

### بوابة الاختبارات

```powershell
# تشغيل البوابة الكاملة:
# smoke-test.mjs + prayer-regression-test.mjs + cargo test --workspace + npm run test:vnext
npm test
```

> **ملاحظة حول ملفات النموذج المبدئي القديمة (`index.html`, `app.js`, `styles.css`, `server.mjs`):** التطبيق الرسمي المُشحون لنظام Windows يعتمد بالكامل على `apps/app-ui` (`dist-vnext/`)، بينما تبقى ملفات النموذج القديم محفوظة حاليًا فقط لتشغيل اختبارات التوافق والانحدار (`smoke-test.mjs` و`prayer-regression-test.mjs`).

## هيكل المشروع

| المسار | الوصف |
|---|---|
| `apps/app-ui/` | الواجهة الرسمية `React 19 + TypeScript + Vite` التي تُبنى إلى `dist-vnext/` |
| `src-tauri/` | غلاف Windows Desktop الأصلي (`Tauri v2`، شريط المهام Win32، الكبسولة، الصوت، المجدول، IPC) |
| `crates/core-rust/` | نواة Rust المشتركة: الحساب الفلكي للصلوات، `SQLite v3`، النماذج، الترحيل، وبدائيات المزامنة المحلية |
| `crates/module-runtime/` | فاحص ومُثبّت حزم البيانات `.wenspack` (توقيع Ed25519، حماية ضد Zip Bomb وPath Traversal) |
| `overlay.*`, `pet.*`, `shared.js`, `island-data.js`, `companion-sounds.js` | أصول الكبسولة الذكية والرفيق العائم التي تُزامنها `sync-desktop-assets.mjs` |
| `fonts/`, `audio/` | خط `Amiri Quran` للآيات في الكبسولة والأصول الصوتية المحلية |
| `contracts/` | مخططات JSON العامة (`ModuleManifest v1`، `SyncEnvelope v1`، وبيان الأصول الصوتية) |
| `scripts/` | سكربتات النشر (`deploy-desktop.ps1`)، التوقيع الرقمي (`sign-release.ps1`)، وتوليد الصوت (`generate-audio.mjs`) |
| `apps/android-shell/` | تكامل Android التجريبي (خارج نطاق إطلاق Windows v1.0.0) |
