### 1.2 Gentle Chime (`gentle-chime.wav`)
- **Origin**: Procedurally generated by `scripts/generate-audio.mjs` using mathematical synthesis (528Hz harmonic bell with exponential decay).
- **License**: Creative Commons CC0 1.0 Universal (Dedicated to the Public Domain)
- **Format**: 16-bit PCM WAV, 44.1kHz mono (2.4 seconds)
- **SHA-1**: `b5610000ef43e02c78324bbe49b0ab75e657b1bd`

### 1.3 Work Focus Chime (`work-chime.wav`)
- **Origin**: Procedurally generated by `scripts/generate-audio.mjs` using mathematical synthesis (two-tone chord transition E5 -> A5).
- **License**: Creative Commons CC0 1.0 Universal (Dedicated to the Public Domain)
- **Format**: 16-bit PCM WAV, 44.1kHz mono (2.0 seconds)
- **SHA-1**: `ca40d7e773e2e6f5459678eeebd0623f806da90b`

### 1.4 Strong Wake-Up Alarm (`strong-alarm.wav`)
- **Origin**: Procedurally synthesized local PCM WAV alert tone created specifically for Wens' opt-in Suhoor wake-up alarm (multi-pulse dual-frequency acoustic wake signal; zero third-party copyrighted samples).
- **License**: Creative Commons CC0 1.0 Universal (Dedicated to the Public Domain)
- **Format**: 16-bit PCM WAV, 44.1kHz mono (4.0 seconds, 352,844 bytes)
- **SHA-1**: `8576a7e7c8e570ac4777fd029167196ceed41f4c`
- **Use in Wens**: Opt-in only (disabled on fresh installs; plays only when the user enables fasting/Suhoor alarms and selects `"strong-alarm"` or tests the alarm).
